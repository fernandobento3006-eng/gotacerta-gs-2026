## O projeto

O GotaCerta usa as leituras de hora em hora dos hidrômetros inteligentes que a Sabesp começou a instalar em 2026 para avisar a família quando aparece um possível vazamento dentro de casa. O aplicativo, ou o WhatsApp para quem não usa app, mostra a causa provável e um teste simples para confirmar o problema. Mudanças na conta ou no abastecimento continuam sendo decididas por um funcionário da Sabesp.
